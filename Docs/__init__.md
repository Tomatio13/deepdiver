# ddaword_cli/__init__.py 詳細設計

## 目的
- パッケージレベルで公開する API を限定し、`ddaword_cli.cli_main` をエクスポートする。

## 内容
- ドキュメンテーション文字列で CLI の概要を示し、`__all__ = ["cli_main"]` を設定してワイルドカード import 時の公開対象を制御。

## 注意事項
- 追加の公開関数が必要になった場合でも、ここでは import/エクスポートのみに留め、ビジネスロジックを記述しない。
- パッケージ初期化副作用を避け、CLI 実行以外のシナリオ（例: テスト、ライブラリとしての再利用）でも安全に import できる状態を保つ。
